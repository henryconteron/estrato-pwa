RESPALDO COMPLETO

Protege tu trabajo

El JSON contiene campañas, estaciones, muestras, todas sus fotos, borradores, papelera, versiones anteriores y capas y fondos del mapa. Guarda una copia fuera del navegador después de cada jornada.

La importación muestra una vista previa. IDs iguales de distintos celulares se conservan con una numeración nueva. Admite respaldos v1, v2, v3 y v4. El respaldo v4 incluye mapas base y requiere Estrato v1.6 o posterior.

Antes de salir al campo

Abre la app con conexión y espera «Lista para usar offline». Instálala y prueba abrirla en modo avión. No borres los datos del sitio ni uses modo privado. El navegador puede negar el almacenamiento persistente; mantén respaldos JSON externos.

Para instalar en iPhone: abre en Safari, usa Compartir → Añadir a pantalla de inicio. En Android: menú de Chrome → Instalar app.
